# Contributing to SmartForms

First off, thank you for considering contributing to SmartForms! It's people like you that make open source such a great community.

We welcome contributions of all kinds, from bug reports and feature requests to code contributions and documentation improvements. This project is meant to be beginner-friendly, so don't hesitate to jump in!

## Where do I start?

If you are new to open source or this project, here is how you can help:
- **Found a bug?** Open an issue on our [issues page](https://github.com/aasif-10/SmartForms/issues).
- **Have a feature request?** We'd love to hear it! Open an issue and label it as an enhancement.
- **Want to write some code?** Check out the issues labeled with `good first issue` or `help wanted`.

## How to contribute code

1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/SmartForms.git
   ```
3. **Create a branch** for your feature or bug fix:
   ```bash
   git checkout -b my-awesome-feature
   ```
4. **Make your changes** and commit them with descriptive messages.
5. **Push your branch** to your forked repository:
   ```bash
   git push origin my-awesome-feature
   ```
6. **Open a Pull Request** against the `main` branch of the original repository. 

## Setting up the development environment

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the build script to compile the extension:
   ```bash
   npm run build
   ```
4. Load the extension in Chrome (via `chrome://extensions/` -> **Load unpacked** -> select the `dist` folder).

## Code Style

- Keep your code clean, readable, and well-documented.
- Try to follow the existing coding conventions in the repository.
- If you're unsure about something, just ask in your Pull Request!

## Need Help?

Don't be afraid to ask questions! If you get stuck, feel free to leave a comment on the issue you are working on, and a maintainer will be happy to guide you.

Happy coding! 🎉
