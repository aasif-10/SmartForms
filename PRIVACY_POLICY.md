# SmartForms Privacy Policy

**Effective Date:** September 2026

## Overview

SmartForms is a privacy-first Chrome extension that helps users save and reuse form values.

## Data Collection

SmartForms does not collect, transmit, or sell user data.

## Data Storage

All saved form values are stored locally in the user's browser using `chrome.storage.local`. SmartForms does not store or synchronize any user data on external servers.

## External Network Requests

SmartForms makes zero external network requests. The extension operates entirely offline within your browser.

## Privacy

SmartForms is designed from the ground up with user privacy as its core principle. Because all saved values remain exclusively in local browser storage and no external network connections are made, your data remains strictly private and under your control.

## Policy Updates

Any future updates to this Privacy Policy will be published directly within the SmartForms repository.
